# E-Recepti
Aplikacija E‑Recepti omogoča shranjevanje, pregledovanje, urejanje in brisanje receptov. Pri vsakem receptu lahko zabeležimo ime, kategorijo, čas priprave, opis, sestavine in navodila. Recepti so iskani po imenu, opisu ali sestavinah, filtrirani po kategoriji, času priprave in sestavini ter razvrščeni po imenu ali času priprave.
